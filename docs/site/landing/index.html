Your Logitech mouse, finally native.

Optune is the open-source Options+ replacement for macOS — battery, DPI, SmartShift, gestures and button remapping from one beautiful menu bar app. No account. No telemetry. No daemons.

Download for macOS Read the docs
$brew install --cask sanjays2402/optune/optune
Features

Everything Options+ does.
Nothing it shouldn’t.

Talks HID++ straight to your device over IOKit — no kernel extensions, no background service, no sign-in.

🔋

Battery insights

14 days of history, drain rate, time-remaining estimates and a per-device low-battery alert.

🎯

DPI stages

Save up to six stages, switch from the menu bar in a click, or cycle with ⌃⌥D from anywhere.

🖐

Gesture button

Hold the thumb button and swipe up, down, left or right — each direction runs its own action.

🧭

Button remapping

Keystrokes, media keys, Mission Control, apps, shell commands and device modes on any control.

🪟

Per-app profiles

DPI and SmartShift follow the app you’re in — Figma, Xcode, Final Cut, whatever you use.

⌨️

Hosts & keyboard

See paired hosts, switch Easy-Switch slots, control backlight and Fn-lock.

Screenshots

Glass, all the way down.

Layered Liquid Glass surfaces and an ambient backdrop — native glass on macOS 26, a faithful material look on macOS 15.

Install

Up and running in a minute.

Requires macOS 15 or later. Grant Input Monitoring (and Accessibility for remaps) when asked.

Homebrew

Recommended — stays up to date.

brew tap sanjays2402/optune
brew install --cask optune

Manual

Grab the DMG, drag Optune to Applications. First launch: right-click → Open (ad-hoc signed).

github.com/Sanjays2402/optune/releases

CLI

Script your mouse; most commands accept --json.

$ optune battery
MX Master 3S — 78%, discharging
$ optune dpi 6400
