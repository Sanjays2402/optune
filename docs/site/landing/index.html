Logitech Options+, minus the account.

Optune is a menu bar app and command-line tool for Logitech MX mice. It reads the battery, sets DPI and SmartShift, and remaps buttons and gestures — straight over HID++. No login, no telemetry, no background service.

01 — What it does

The parts of Options+ you actually use.

Battery

Live level and charge state, 14 days of history, drain rate and a time-remaining estimate. Low-battery alert threshold is set per device.

0x1004

DPI

Slider for the full range, plus up to six saved stages you can click in the menu bar, cycle from a button, or step through with ⌃⌥D.

0x2201

SmartShift

Toggle and sensitivity for the ratchet/free-spin wheel, and the hi-res and thumb-wheel settings alongside it.

0x2111 · 0x2121 · 0x2150

Buttons

Rebind any reprogrammable control to a keystroke, media key, Mission Control, an app, or a shell command.

0x1B04

Gestures

Hold the gesture button and swipe up, down, left or right — four more actions, one per direction. A plain press still does its own thing.

0x1B04 raw XY

Profiles

DPI and SmartShift follow whichever app is in front.

Hosts

See paired Easy-Switch hosts and jump between them.

02 — Under the hood

Small, boring, and out of your way.

No daemon

Optune only runs while the menu bar app is open. It polls your device about once a minute over IOKit HIDManager — no kernel extension, no helper tool, no launch agent unless you ask for launch-at-login.

Quiet on the network

The one request it makes is an optional update check to api.github.com for the latest release. Nothing about your devices leaves the machine.

Plain files

Your settings live in one JSON file, ~/Library/Application Support/Optune/devices.json. Export and import are in the File menu.

04 — Supported devices

Nine mice today.

  • MX Master 4
  • MX Master 3S
  • MX Master 3
  • MX Master 2S
  • MX Master
  • MX Vertical
  • MX Anywhere 3S
  • MX Anywhere 3
  • MX Anywhere 2S

Keyboard features (backlight, Fn-lock) exist in the core, but keyboards aren’t in the device list yet. Something missing? Run optune devices --json --all and open an issue — adding a device is a one-file change to devices.json.

05 — From the terminal

Everything the app does, scriptable.

$ optune battery
MX Master 3S — 78%, discharging (Bluetooth)

$ optune dpi 6400
MX Master 3S — applied 6400 dpi

$ optune smartshift --off
MX Master 3S — SmartShift disabled

$ optune devices --json
06 — Install

Two ways, about a minute.

  1. Homebrew

    Keeps you on the latest release.

    $ brew tap sanjays2402/optune
$ brew install --cask optune

  2. Or the DMG

    Download it from GitHub Releases and drag Optune to Applications. The build is ad-hoc signed, so the first launch needs right-click → Open.

  3. Grant two permissions

    Input Monitoring lets Optune talk to the device. Accessibility is only needed for remaps that send keystrokes. macOS asks the first time each is needed.
